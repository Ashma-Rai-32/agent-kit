# agent-kit

My Claude Code plugins and skills, set up so I can install them on any laptop.

## Install

```bash
claude plugin marketplace add Ashma-Rai-32/agent-kit
claude plugin install frontend@ashma-skills
```

Start a new Claude Code session after installing.

## What's inside

| Plugin   | Skill              | What it does                                    |
|----------|--------------------|-------------------------------------------------|
| frontend | `/frontend:design` | Builds clean, accessible UIs with React/Next.js |

Claude picks the skill up on its own when you ask for UI work. You can also run it directly.

## Updating

```bash
claude plugin marketplace update ashma-skills
claude plugin update frontend@ashma-skills
```
